====================================================================
           GUÍA DE EJECUCIÓN LOCAL DEL SISTEMA SYSTMA
====================================================================

Este archivo detalla los pasos para levantar y ejecutar el sistema 
completo (Backend Django + Frontend React) en un entorno local.


--------------------------------------------------------------------
1. REQUISITOS PREVIOS
--------------------------------------------------------------------
Asegúrate de tener instalados en tu computadora:
  - Python 3.10 o superior (con pip)
  - Node.js 18 o superior (con npm)
  - PostgreSQL 14 o superior instalado y en ejecución


--------------------------------------------------------------------
2. CREACIÓN DE LA BASE DE DATOS (POSTGRESQL)
--------------------------------------------------------------------
Crea una base de datos en PostgreSQL para el sistema:
  - Nombre de la base de datos sugerido: db_gestion_tic
  - Ejemplo en consola psql:
      CREATE DATABASE db_gestion_tic;


--------------------------------------------------------------------
3. CONFIGURACIÓN Y EJECUCIÓN DEL BACKEND (DJANGO)
--------------------------------------------------------------------
Abre una terminal y navega hasta la carpeta 'backend':

  cd backend

Paso 3.1: Crear y activar el entorno virtual de Python
  - En Mac / Linux:
      python3 -m venv venv
      source venv/bin/activate
  - En Windows:
      python -m venv venv
      venv\Scripts\activate

Paso 3.2: Instalar las dependencias
      pip install -r requirements.txt

Paso 3.3: Configurar variables de entorno (.env)
  - Copia el archivo de ejemplo:
      cp .env.example .env     (o cópialo manualmente en Windows)
  - Abre el archivo '.env' y ajusta tus credenciales:
      DEBUG=True
      ALLOWED_HOSTS=localhost,127.0.0.1
      DATABASE_URL=postgresql://usuario_postgres:tu_password@localhost:5432/db_gestion_tic
      DB_SSL=False
      CORS_ALLOWED_ORIGINS=http://localhost:5173,http://127.0.0.1:5173
      CSRF_TRUSTED_ORIGINS=http://localhost:5173,http://127.0.0.1:5173
      FRONTEND_URL=http://localhost:5173
      
      # Credenciales de correo (opcional, para envíos reales por SMTP):
      EMAIL_HOST_USER=tu_correo@gmail.com
      EMAIL_HOST_PASSWORD=tu_app_password

Paso 3.4: Aplicar migraciones a la base de datos
      python manage.py migrate

Paso 3.5: Crear el usuario Administrador principal
      python manage.py createsuperuser
  (Ingresa tu usuario, correo y contraseña deseada)

Paso 3.6: Iniciar el servidor Backend
      python manage.py runserver 127.0.0.1:8000

El backend quedará activo en: http://127.0.0.1:8000/


--------------------------------------------------------------------
4. CONFIGURACIÓN Y EJECUCIÓN DEL FRONTEND (REACT + VITE)
--------------------------------------------------------------------
Abre OTRA terminal (manteniendo abierta la del backend) y entra a 'frontend':

  cd frontend

Paso 4.1: Instalar dependencias de Node.js
      npm install

Paso 4.2: Configurar variables de entorno del frontend (.env)
  - Copia o crea el archivo '.env':
      cp .env.example .env     (o cópialo manualmente en Windows)
  - Asegúrate de que contenga:
      VITE_API_URL=http://127.0.0.1:8000/api/

Paso 4.3: Iniciar el servidor de desarrollo del Frontend
      npm run dev

El frontend quedará activo en: http://localhost:5173/


--------------------------------------------------------------------
5. ACCESO AL SISTEMA
--------------------------------------------------------------------
  - Aplicación Web Principal:  http://localhost:5173
  - Panel Django Administrador: http://127.0.0.1:8000/admin/

Inicia sesión con el usuario y contraseña de Administrador que 
creaste en el Paso 3.5 para comenzar a crear personal, clientes y órdenes.
